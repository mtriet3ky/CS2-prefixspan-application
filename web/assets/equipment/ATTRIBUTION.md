# CS:GO equipment HUD icons

Valve CS:GO Panorama equipment SVG assets, mirrored by Juknum/counter-strike-icons.
Pinned commit: 57a08657e1c2f1e6875c8b79575c23d4b6eb285a.
Source: https://github.com/Juknum/counter-strike-icons/tree/57a08657e1c2f1e6875c8b79575c23d4b6eb285a/csgo/materials/panorama/images/icons/equipment

Original source license and README are preserved as SOURCE_LICENSE and SOURCE_README.md; per-file original SHA256 and URLs are in manifest.json. Valve owns the game assets. This educational demo does not claim ownership of the assets.

Name mapping follows the human-readable names used by demoinfocs / ESTA. Notably M4A1 means the suppressed M4A1-S (m4a1_silencer.svg), whereas M4A4 uses m4a1.svg. Molotov and Incendiary Grenade use distinct assets. Knife in the source does not identify cosmetic variants: the generic CT or T knife icon is used, without inferring a knife skin. Unknown weapon names retain text without an invented icon.

Mapping reference: https://github.com/markus-wa/demoinfocs-golang/blob/v2.13.3/pkg/demoinfocs/common/equipment.go
